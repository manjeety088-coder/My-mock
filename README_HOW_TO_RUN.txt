HOW TO USE
1. ZIP extract karo.
2. html_site_output folder kholo.
3. Economy_Spl-12.html open karo. Ye home page hai.
4. PDF page bhi batch name ke saath hai: Economy_Spl-12__PDF.html
5. Chapter pages bhi batch name ke prefix ke saath bane hain.

ALL JSON FILES KE LIYE
1. build_multi_batch_site.py ko apne JSON files wale folder me paste karo.
2. Jitni JSON files hain sab usi folder me rakho.
3. CMD open karke run karo: python build_multi_batch_site.py
4. html_site_output folder me har batch ka Batch_Name.html ban jayega.
5. index.html nahi banega. Optional launcher ka naam All_Batches.html hai.
